# Source Document Register

Every form in this app is transcribed from an official Child First / CPP fidelity
document. This register records provenance for each instrument. Files in this
folder are blank official forms (no client data). Documents not stored here are
in the owner's Google Drive (links below require Drive access).

All instruments © Child First / Child-Parent Psychotherapy. This app is a
personal digitization aid; the instruments remain the property of their authors.
